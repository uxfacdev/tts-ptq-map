# What Breaks When You Quantize On-Device TTS?

### A Cross-Architecture Study of Post-Training Quantization

Code repository for the paper *"What Breaks When You Quantize On-Device TTS? A Cross-Architecture Study of Post-Training Quantization,"* submitted to **ICASSP 2027**.

## Overview

This repository accompanies our study of post-training quantization (PTQ) applied to on-device text-to-speech (TTS) models across multiple architectures. We analyze where quantization degrades output quality, which components are most sensitive, and how these failure modes differ across model families.

Code, experiment configs, and evaluation scripts will be added here as the paper progresses through review.
